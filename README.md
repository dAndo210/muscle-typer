**demoです。(2026/6/5)**

## 遊び方
* 「プレイ」を押してゲームを起動すると、30字くらいの文章と、テキストエリアが現れます。
* 文章を正しくタイプすると、結果としてその精度や速度に応じてノルマが加算されます。

### 育成要素について
* プレイを重ねると、すこーしずつ筋肉が成長していきます。
* 継続的にタイピングを行ってもらうことを想定しているため、ノルマが100%の時にプレイしても筋肉は成長しません（プレイは可能です）。
* マッスルボディ（アーム）を目指しましょう。

## 見つかってるバグ
* apiキーを隠す方法を模索中
* Backspaceキーを押した数をもとにタイピング精度を判定しているので、Deleteキーや範囲選択からの一括消去、Ctrl+Backspaceを行うと、正しく判定できません。
* localStorageにデータがnullの状態で「前回の結果」ボタンを押すと、エラーになる

## 追加したい要素

* 文章の形式とかを選べるようにする（記号多めとか）
